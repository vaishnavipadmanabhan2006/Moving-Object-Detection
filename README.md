#  Moving Object Detection

This project uses **Python** and **OpenCV** to detect and track moving objects in video streams.  
The script `new_face.py` demonstrates **motion detection** and **visualization techniques**.

---

##  Features
- 🎥 Frame capture and processing with OpenCV  
- 🔍 Motion detection using frame differencing  
- 📦 Object tracking with bounding box visualization  
- ⚡ Easy to extend for custom datasets or camera input  

---

##  Requirements
- 🐍 Python 3.14 (or compatible version)  
- 📷 OpenCV (`cv2`)  
- 🔢 NumPy
